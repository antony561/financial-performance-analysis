# Financial Performance Analysis

## Overview
Analysed financial expense data across 3 Australian cities (Adelaide, Melbourne, Sydney) 
to uncover budget performance, expense trends and quarterly patterns.

## Tools Used
- SQL (SQLite) — data extraction and analysis
- Microsoft Excel — visualisation and dashboards

## Key Findings
- Sydney was the only city under budget (saved $391)
- Salary accounts for 66% of total expenses
- Q2 had the highest quarterly spending at $22,171
- February recorded the highest monthly spending

## Files
- `queries.sql` — all SQL queries used for analysis
- `Financial_Performance_Analysis.xlsx` — charts and data summary
- `Report.docx` — full insights report
